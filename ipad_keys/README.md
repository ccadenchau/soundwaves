# iPad keys

Standalone falling-note keyboard, independent of Soundwaves and Flask.

```sh
python3 -m http.server 8765 --bind 0.0.0.0 --directory ipad_keys
```

Open http://localhost:8765 on this computer, or http://YOUR_COMPUTER_IP:8765 on an iPad on the same Wi-Fi. Choose a demo or open a MIDI file, then tap Play. Stop with Ctrl+C.
